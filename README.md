🌍 Travel & Tourism Website
📌 Project Description

The Travel & Tourism Website is a simple and attractive web application designed to help users explore popular tourist destinations and travel packages.

Users can view destination information, explore different travel packages, submit a trip booking request, and contact the travel service through the website.

This project is developed using HTML, CSS, and JavaScript and can be run directly using VS Code Live Server.

🎯 Objectives

To create an attractive travel and tourism website.

To provide information about popular tourist destinations.

To display different travel packages and prices.

To allow users to submit a travel booking request.

To provide an easy-to-use contact form.

To create a responsive website for desktop and mobile devices.

🛠️ Technologies Used

HTML5 – Creates the structure of the website.

CSS3 – Provides styling, layout, animations, and responsive design.

JavaScript – Adds interactive features and form validation.

Visual Studio Code – Used for development.

Live Server – Used to run the website locally.

✨ Features
🏠 Home Page

The home page introduces the TravelGo website and provides an "Explore Destinations" button.

🌎 Popular Destinations

Users can explore popular destinations such as:

Paris

Bali

Dubai

London

Each destination contains information and an Explore button.

🧳 Travel Packages

The website provides different travel packages:

Basic Package

Premium Package

Family Package

Each package includes the price, duration, accommodation, meals, and other services.

📅 Trip Booking

Users can click Book Now or Book Package and enter:

Full name

Email

Destination

Travel date

Number of travelers

JavaScript validates the booking form and displays a booking confirmation.

📩 Contact Form

Users can send a message by entering:

Name

Email

Message

📱 Responsive Design

The website is designed to work on:

Desktop

Laptop

Tablet

Mobile devices

🚀 How to Run
Step 1

Download or copy the project to your computer.

Step 2

Open the project folder in Visual Studio Code.

Step 3

Make sure the following files are available:

index.html
style.css
script.js
README.md

Step 4

Open index.html.

Step 5

Right-click on index.html and select:

Open with Live Server

The website will open automatically in your browser.
